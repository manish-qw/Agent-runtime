# Architecture Planning Rule

Whenever you are tasked with creating a project plan or making architectural decisions, you MUST follow this protocol:

1. **Do not make unilateral architectural decisions**: Always ask the user for their preference before finalizing the design.
2. **Provide Options**: Present the viable architectural options clearly.
3. **Pros and Cons**: Detail the advantages and disadvantages of each option.
4. **Recommendation**: Suggest the best option for the current context and justify why it fits best.
5. **Wait for Approval**: Stop and wait for the user to select an option or provide feedback before moving forward with execution.
